# Security Policy

We appreciate reports that help us keep our projects and users safe.

## Reporting a vulnerability

**Please don't open a public issue for security problems.**

Preferred: use **[GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)**
on the affected repository (the *Security* tab → *Report a vulnerability*).

Or email **security@heuro.studio** with:

- What the issue is and where you found it
- Steps to reproduce, if you have them
- Anything that helps us understand the impact

We'll acknowledge your report as soon as we can and keep you updated as we work
on a fix. If you'd like credit for the find, just say so.
