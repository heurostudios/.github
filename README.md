# .github

Org-wide **public** defaults for [Heuro Studios](https://heuro.studio).

- [`profile/README.md`](profile/README.md) — the org profile shown at [github.com/heurostudios](https://github.com/heurostudios).
- [`CONTRIBUTING.md`](CONTRIBUTING.md), [`SECURITY.md`](SECURITY.md) and the issue/PR templates
  in [`.github/`](.github) act as fallback community health files for any org repo — public or
  private — that doesn't define its own.

Internal conventions (repo naming, branch naming, commit trailers) live in the private
`.github-private` repo, since GitHub only serves org-wide defaults from a public repo.
